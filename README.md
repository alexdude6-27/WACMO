# WACMO Website

The Washington Association of Competitive Mounted Orienteering
(WACMO) brings riders together for navigation adventures on horseback.

This project is modernizing WACMO's website while preserving
the history, photographs, maps, and documents that members
have collected over the years.

## Why Modernize?

Our goal is a welcoming website that works well on desktop
computers and smartphones, helps members find events, and
can eventually be maintained by volunteer webmasters without
specialized programming knowledge.

Preserving WACMO's history is just as important as creating
new features.

## What Has Been Accomplished?

The new website already includes:

- **Events Calendar:** Current and historical event listings,
  including available schedules from 2024 through 2026.
- **Ride Flyers:** Original flyers connected to events and
  organized into a searchable archive.
- **Photo Galleries:** Historical photographs and event albums.
- **Riding-Area Maps:** All 26 maps previously published on
  WACMO's original Maps page, including original printable PDFs.
- **Connected History:** Verified relationships between events,
  maps, flyers, and photographs.
- **Responsive Design:** Navigation and pages designed for
  phones, tablets, and desktop computers.

Historical event listings do not necessarily confirm that a
ride took place.

Historical maps are reference materials; trails and access
conditions can change.

## What Comes Next?

The major remaining goal is an easy-to-use event management
system for volunteer webmasters.

The intended workflow is:

1. Create an event and add it to the calendar.
2. Upload the event flyer before the ride.
3. Add photographs and an approved map after the ride.
4. Keep the event and its materials together in the archive.

The webmaster editor has not yet been built.

Other remaining work includes a database-backed administration
system, security controls, production testing, and deployment
to a Bluehost VPS.

**The modernized website is still under development.**
The new application has not yet been launched on the VPS.

## Preserving WACMO's History

Original materials have been retained wherever practical.

Published riding-area maps are distinguished from private
competition courses. Unreviewed or upcoming course maps
are not automatically released.

Original photographs, logos, flyers, maps, and other materials
retain their respective rights.
